/files-assistant

Closer to a terminal-friendly Notion extension than an application. This CLI tool is meant for those who want to be able to see any information/notes they dump in Notion directly in the terminal, instead of opening a separate web browser. It makes use of the Notion API and Gemini API to simply retrieve, summarize, and return any information you may be looking for as you develop.

/symptom-tracker

Local desktop Flask application to track the symptoms of patients (mostly for my dad) for easier, more accurate, self-reporting during interval medical check-ups. Meant to be simple, privacy-first weekly health check-in app particularly suitable for chronic patients and seniors. Could also be useful in clinical research settings heavily dependent on long-term self-reporting. All audio recordings are saved locally on your computer. Uses the whisper library and the Gemini API to transcribe multiple audio recordings locally, and then send the transcriptions to Gemini for summary. Considering adding a dynamic database aspect for more dynamic data extraction.

/sierra-local

This is an open-source project I am currently contributing to! It is a tool meant for use in the bioinformatics field specifically for HIV-1 drug resistance predictions. Built based on the Sierra web service from Stanford University, this was started by a professor I got to know during my undergrad, who thought that a local version of Sierra would be more beneficial both in healthcare practices and research. The core of bioinformatics is string matching, improving match accuracy, and validating the results. Still learning more about what that specifically entails when it comes to genome sequences! The tool itself is pretty cool. It's python based, and calls on various APIs to pull publicly available data on known mutations and drug resistance patterns, and then applies that to the inputted genome sequence to predict drug resistance patterns. It's pretty wild that we were able to create drugs that even remotely work because annotating and matching genomic sequences has been a long-standing, major use-case for algorithm theory and has challenged/haunted many a computer-scientist/mathematician. It's a really exciting field to be in, and I'm excited to be contributing to it in some small way.
